# 소음 지킴이 로봇 프로젝트 · 실시간 수업방

3~4학년 과학 카미봇 파이 프로젝트의 **1~4차시 수업 자료**입니다.
학생은 크롬북으로 들어와 답을 입력하고, 선생님은 같은 화면에서 단계를 넘기며
누가 어디까지 답했는지 실시간으로 봅니다.

## 들어 있는 것

| 경로 | 내용 |
|---|---|
| `public/index.html` | 수업 화면 한 장 (1~4차시 모두 포함) |
| `public/files/lesson1-melody.sb3` | 1차시 비트블록 AI 연주 프로젝트 |
| `public/files/lesson4-noise-guard.sb3` | 4차시 AI 소음 지킴이 프로젝트 |
| `netlify/functions/api.mjs` | 답 저장·불러오기 서버 (Netlify Functions + Blobs) |
| `netlify.toml`, `package.json` | Netlify 설정 |

> ⚠️ 서버 기능이 있어서 **Netlify Drop(폴더 끌어다 놓기)으로는 동작하지 않습니다.**
> 아래 두 방법 중 하나로 배포하세요.

## 배포 방법 A — GitHub로 (추천)

1. GitHub에서 새 저장소를 만들고 이 폴더의 파일을 모두 올립니다.
2. Netlify → **Add new site → Import an existing project → GitHub** → 저장소 선택.
3. 빌드 설정은 비워 둡니다. (`netlify.toml`이 알아서 잡습니다.)
4. 배포 전에 **Site configuration → Environment variables**에서 추가:
   - Key: `TEACHER_PIN` / Value: 선생님만 아는 숫자 4~6자리
5. **Deploy** → 주소(예: `https://○○○.netlify.app`)가 나오면 끝.

## 배포 방법 B — Netlify CLI로

```bash
npm install
npm install -g netlify-cli
netlify login
netlify init            # 새 사이트 만들기
netlify env:set TEACHER_PIN 2468   # 원하는 숫자로
netlify deploy --prod
```

`TEACHER_PIN`을 정하지 않으면 기본값 **0000**이 쓰이고, 선생님 화면 위에 경고가 뜹니다.
환경 변수를 바꾼 뒤에는 **다시 배포**해야 적용됩니다.

## 수업에서 쓰는 법

**선생님**
1. 주소로 들어가 차시·반을 고르고 **선생님** 버튼을 켠 뒤 PIN 입력.
2. 위쪽 **QR 입장**을 눌러 전자칠판에 띄웁니다. (QR에 차시·반이 들어 있습니다.)
3. 왼쪽 **오늘 수업 흐름**에서 단계를 누르면 학생 화면도 같이 넘어갑니다.
4. 문항 옆 **답 공개**를 켜면 그 문항의 반 전체 답이 학생 화면에 보입니다.
   끄면 학생은 자기 답만 봅니다.
5. **진행 현황** 탭: 모둠·이름별로 어느 문항에 답했는지(✓), 지금 접속 중인지 보입니다.
6. **결과저장(CSV)**: 반 전체 답을 엑셀에서 열 수 있는 파일로 받습니다.
7. **초기화**: 그 차시·반의 답을 모두 지웁니다. "초기화"라고 직접 입력해야 실행됩니다.
   다음 해에 다시 쓸 때나 연습 후에 사용하세요.

**학생**
1. QR을 찍고 모둠과 이름을 입력해 들어옵니다.
2. 답을 쓰고 **답 등록**을 누릅니다. 고친 뒤 다시 누르면 덮어씁니다.
3. 창을 닫았다가 같은 모둠·이름으로 다시 들어오면 썼던 답이 돌아옵니다.
4. **결과저장**을 누르면 자기 답을 글 파일로 받을 수 있습니다.

## 알아 둘 점

- 답은 **차시 + 반** 단위로 따로 저장됩니다. (예: 2차시 3반)
- 학생은 3초마다 새 내용을 확인합니다. 한 반 25명 기준으로 무료 사용량 안에서 충분합니다.
  사용량은 Netlify 대시보드의 Usage에서 확인할 수 있습니다.
- 이름으로 구분하므로 같은 모둠에 같은 이름을 쓰면 답이 합쳐집니다.
- 학생 실명 대신 번호나 별명을 쓰게 하면 개인정보 걱정을 줄일 수 있습니다.
